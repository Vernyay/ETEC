Eventos JavaScript

Explicação e exemplo de cada evento

Guia 1 - Eventos de Clique

onclick

O que é: executa uma ação sempre que o usuário clica em um elemento.

Sintaxe: elemento.onclick = função

Cliques: 0

ondblclick

O que é: executa uma ação quando o usuário faz dois cliques rápidos no elemento.

Sintaxe: elemento.ondblclick = função

Duplo cliques: 0

onmousedown

O que é: dispara no momento em que o botão do mouse é pressionado sobre o elemento.

Sintaxe: elemento.onmousedown = função

Aguardando...

onmouseup

O que é: dispara quando o botão do mouse é solto após ter sido pressionado.

Sintaxe: elemento.onmouseup = função

Aguardando...

Guia 2 - Eventos do Mouse

onmouseover

O que é: dispara quando o ponteiro do mouse entra dentro do elemento.

Sintaxe: elemento.onmouseover = função

Passe o mouse por aqui

Fora do elemento

onmouseout

O que é: dispara quando o ponteiro do mouse sai do elemento.

Sintaxe: elemento.onmouseout = função

Tire o mouse daqui

Dentro do elemento

onmousemove

O que é: dispara continuamente enquanto o mouse se move dentro do elemento.

Sintaxe: elemento.onmousemove = função

Mova o mouse aqui

X: 0 | Y: 0

Guia 3 - Eventos de Formulários

onfocus

O que é: dispara quando um campo recebe o foco, ou seja, quando o usuário clica nele para começar a digitar.

Sintaxe: elemento.onfocus = função

Campo sem foco

onchange

O que é: dispara quando o valor de um campo é alterado e o usuário confirma a mudança (sai do campo).

Sintaxe: elemento.onchange = função

Nenhuma cor escolhida

onblur

O que é: dispara quando um campo perde o foco, ou seja, quando o usuário sai dele.

Sintaxe: elemento.onblur = função

Campo com foco

Guia 4 - Eventos de Teclado

onkeydown

O que é: dispara no momento em que uma tecla é pressionada para baixo.

Sintaxe: elemento.onkeydown = função

Nenhuma tecla pressionada

onkeypress

O que é: dispara quando uma tecla de caractere é pressionada (letras e números). Não detecta teclas como Shift ou Ctrl.

Sintaxe: elemento.onkeypress = função

Nenhum caractere digitado

onkeyup

O que é: dispara quando uma tecla é solta após ser pressionada.

Sintaxe: elemento.onkeyup = função

Nenhuma tecla solta

Guia 5 - Eventos da Janela

onload

O que é: dispara quando a página (ou uma imagem) terminou de ser carregada completamente.

Sintaxe: window.onload = função

Carregando página...

onresize

O que é: dispara quando a janela do navegador é redimensionada (aumentada ou diminuída).

Sintaxe: window.onresize = função

Largura: 0px | Altura: 0px
